# Knowafest Hackathon Scraper & Supabase Sync

An enhanced, high-performance scraper for extracting structured hackathon information from [Knowafest](https://www.knowafest.com/explore/fest-type/Hackathon) using [Scrapling](https://github.com/D4Vinci/Scrapling) and synchronizing with Supabase.

---

## 1. Extracted Structured Fields (All 17 Fields)

Every hackathon record is extracted dynamically and normalized into the following 17 standard fields:

| Field Name | Type | Description | Fallback when Missing |
| :--- | :--- | :--- | :--- |
| `title` | `TEXT` | Event title from page card header / listing microdata | **Required** |
| `organizer` | `TEXT` | Hosting college or organization | `null` |
| `status` | `TEXT` | `Upcoming`, `Ongoing`, `Completed`, or `Closed` | `null` |
| `location` | `TEXT` | City/State or `"Online"` | `null` |
| `event_mode` | `TEXT` | Disambiguated into `"Online"`, `"Offline"`, or `"Hybrid"` | `null` |
| `start_date` | `DATE` | Strict ISO `YYYY-MM-DD` | `null` |
| `end_date` | `DATE` | Strict ISO `YYYY-MM-DD` (for multi-day events) | `null` |
| `registration_deadline` | `DATE` | Strict ISO `YYYY-MM-DD` | `null` |
| `team_size_min` | `INT` | Minimum team size integer | `null` |
| `team_size_max` | `INT` | Maximum team size integer | `null` |
| `prize` | `TEXT` | Original verbatim prize text (e.g. `Prize Pool: ₹22,000`) | `null` |
| `prize_amount` | `NUMERIC` | Calculated numeric amount (e.g. `22000.0`) | `null` |
| `currency` | `TEXT` | ISO Currency code (`INR`, `USD`, `EUR`, `GBP`) | `null` |
| `tags` | `TEXT[]` | Cleaned and deduplicated list of domains/departments | `[]` |
| `source_url` | `TEXT` | Canonical detail page URL | **Required (Unique)** |
| `source_website` | `TEXT` | Domain extracted dynamically (`knowafest.com`) | `null` |
| `scraped_at` | `TIMESTAMPTZ` | UTC ISO timestamp (`YYYY-MM-DDTHH:MM:SSZ`) | Generated at runtime |

---

## 2. Supabase Integration & Database Migration

The scraper syncs records into the Supabase `hackathons` table with automatic conflict resolution on `source_url`.

### Migration SQL
Execute [`supabase_migration.sql`](supabase_migration.sql) in your [Supabase SQL Editor](https://supabase.com/dashboard/project/_/sql) to ensure the table and indexes exist:

```sql
-- Create table if not exists
CREATE TABLE IF NOT EXISTS hackathons (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title TEXT NOT NULL,
    organizer TEXT,
    status TEXT,
    location TEXT,
    event_mode TEXT,
    start_date DATE,
    end_date DATE,
    registration_deadline DATE,
    team_size_min INT,
    team_size_max INT,
    prize TEXT,
    prize_amount NUMERIC,
    currency TEXT,
    tags TEXT[] DEFAULT '{}'::TEXT[],
    source_url TEXT NOT NULL,
    source_website TEXT,
    scraped_at TIMESTAMPTZ DEFAULT NOW(),
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Unique index for idempotent deduplication & upsert
CREATE UNIQUE INDEX IF NOT EXISTS idx_hackathons_source_url ON hackathons(source_url);

-- Fast query indexes
CREATE INDEX IF NOT EXISTS idx_hackathons_source_website ON hackathons(source_website);
CREATE INDEX IF NOT EXISTS idx_hackathons_status ON hackathons(status);
CREATE INDEX IF NOT EXISTS idx_hackathons_start_date ON hackathons(start_date);
CREATE INDEX IF NOT EXISTS idx_hackathons_registration_deadline ON hackathons(registration_deadline);
```

## 3. Configuration

Configure your Supabase credentials in `.env`:

```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-service-role-or-anon-key
SUPABASE_TABLE=hackathons
```

---

## 4. Running the Scraper

### Full Scrape
Scrape all active hackathons and sync to Supabase:
```powershell
python scraper.py
```

### Limited Scrape (e.g. 5 hackathons)
```powershell
python scraper.py --limit 5
```

### Skip Supabase (Local export only)
```powershell
python scraper.py --skip-supabase
```
