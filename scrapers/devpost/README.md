# Devpost Hackathon Scraper

A high-performance, robust web scraper built with [Scrapling](https://github.com/D4Vinci/Scrapling) to extract structured data from ongoing and upcoming [Devpost](https://devpost.com) hackathons, with automatic synchronization to **Supabase** and local exports to **JSON** and **CSV**.

---

## Features

- **Deep Detail Page Extraction**: Parses detail page DOM, labels, microdata, and schema.org JSON-LD to capture comprehensive hackathon metadata.
- **Strict Zero-Fabrication Policy**: Missing fields evaluate strictly to `null` / `None` or `[]`. No placeholder text, copied data, or fabricated defaults.
- **Normalized Data Formats**:
  - **Dates**: Normalized to ISO `YYYY-MM-DD` (`start_date`, `end_date`, `registration_deadline`).
  - **Team Sizes**: Dynamically parsed into `team_size_min` and `team_size_max` integers (e.g. `1-3`, `2–5`, `Team required: 2 to 6 members`).
  - **Prizes & Currencies**: Preserves raw prize string, normalizes numeric `prize_amount`, and detects `currency` (e.g. `USD`, `INR`, `EUR`, handling Lakhs, Crores, K, M).
  - **Location & Mode**: Separates physical address/city from `event_mode` (`Online`, `Offline`, `Hybrid`).
  - **Tags**: Deduplicated list of themes, technologies, and skills.
- **Supabase Integration & Idempotent Upsert**:
  - Automatically deduplicates records in-memory and in PostgreSQL on unique `source_url`.
  - Re-running the scraper updates existing records without creating duplicates.
  - Supports both `supabase-py` client and direct PostgREST REST fallback.
- **Multi-Format Export**: Saves results to `hackathons.json` and `hackathons.csv` on every run.

## Extracted Data Schema

| Field | Type | Description | Example Value |
|---|---|---|---|
| `title` | `TEXT` | Full name of the hackathon | `"The Rice University Urban Sustainability Hackathon"` |
| `organizer` | `TEXT` | Host / Organizing entity | `"Rice University"` |
| `status` | `TEXT` | State of the event (`open`, `upcoming`) | `"open"` |
| `location` | `TEXT` | Cleaned location or physical address | `"Online"` |
| `event_mode` | `TEXT` | Delivery format (`Online`, `Offline`, `Hybrid`) | `"Online"` |
| `start_date` | `DATE` | Event start date in ISO format | `"2026-06-23"` |
| `end_date` | `DATE` | Event end date in ISO format | `"2026-09-18"` |
| `registration_deadline` | `DATE` | Deadline date in ISO format | `"2026-09-18"` |
| `team_size_min` | `INT` | Minimum allowed team size | `2` |
| `team_size_max` | `INT` | Maximum allowed team size | `6` |
| `prize` | `TEXT` | Original displayed prize string | `"$ 17,500 in cash"` |
| `prize_amount` | `NUMERIC` | Normalized numeric prize value | `17500` |
| `currency` | `TEXT` | Currency ISO code (`USD`, `INR`, `EUR`, etc.) | `"USD"` |
| `tags` | `TEXT[]` | List of tags and themes | `["Design", "Social Good", "Databases"]` |
| `source_url` | `TEXT` | Canonical detail page URL (Unique key) | `"https://rice-urban-sustainability.devpost.com/"` |
| `source_website` | `TEXT` | Domain of the source website | `"devpost.com"` |
| `scraped_at` | `TIMESTAMPTZ` | Timestamp when the record was scraped | `"2026-09-14T13:37:55.616151+00:00"` |

## Setup & Installation

### 1. Prerequisites

- Python 3.10+
- Virtual environment (recommended)

### 2. Clone & Install Dependencies

```bash
git clone https://github.com/naveedsheriffj/devpost.git
cd devpost

# Create and activate virtual environment
python -m venv .venv
# On Windows PowerShell:
.\.venv\Scripts\Activate.ps1
# On macOS/Linux:
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### 3. Configure Environment Variables

Create a `.env` file in the project root:

```env
SUPABASE_URL=https://your-project-ref.supabase.co
SUPABASE_KEY=your-supabase-anon-or-service-role-key
```

> **Note**: If `SUPABASE_URL` and `SUPABASE_KEY` are not set, the scraper will still extract and save data locally to `hackathons.json` and `hackathons.csv`.

## Supabase Database Migration

Before syncing data to Supabase, run [supabase_migration.sql](file:///c:/Users/naveed%20sheriff%20j/Desktop/devpost/supabase_migration.sql) in your [Supabase SQL Editor](https://supabase.com/dashboard/project/_/sql):

```sql
-- 1. Create hackathons table
CREATE TABLE IF NOT EXISTS hackathons (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title TEXT NOT NULL,
    organizer TEXT,
    status TEXT,
    location TEXT,
    event_mode TEXT,
    start_date DATE,
    end_date DATE,
    registration_deadline DATE,
    team_size_min INT,
    team_size_max INT,
    prize TEXT,
    prize_amount NUMERIC,
    currency TEXT,
    tags TEXT[] DEFAULT '{}'::TEXT[],
    source_url TEXT NOT NULL,
    source_website TEXT,
    scraped_at TIMESTAMPTZ DEFAULT NOW(),
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Add columns if table already exists
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS title TEXT;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS organizer TEXT;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS status TEXT;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS location TEXT;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS event_mode TEXT;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS start_date DATE;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS end_date DATE;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS registration_deadline DATE;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS team_size_min INT;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS team_size_max INT;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS prize TEXT;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS prize_amount NUMERIC;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS currency TEXT;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS tags TEXT[] DEFAULT '{}'::TEXT[];
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS source_url TEXT;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS source_website TEXT;
ALTER TABLE hackathons ADD COLUMN IF NOT EXISTS scraped_at TIMESTAMPTZ DEFAULT NOW();

-- 3. Unique index for deduplication & upsert
CREATE UNIQUE INDEX IF NOT EXISTS idx_hackathons_source_url ON hackathons(source_url);
```

## Usage

### Run Default Scrape & Sync to Supabase

```bash
python scraper.py
```

### Scrape Specific Page

```bash
python scraper.py --page 2
```

### Scrape All Available Pages

```bash
python scraper.py --all-pages
```

### Run in Offline / Local-Only Mode (No Supabase Sync)

```bash
python scraper.py --page 2 --no-supabase
```

### Skip Fetching Individual Detail Pages (Fast Mode)

```bash
python scraper.py --no-details
```

### Custom Output File Paths

```bash
python scraper.py --json-out data/custom.json --csv-out data/custom.csv
```

## CLI Options Reference

| Option | Type | Default | Description |
|---|---|---|---|
| `--page` | `int` | `2` | Target page number to start scraping |
| `--all-pages` | `flag` | `False` | Scrape all available pages until the last page |
| `--no-details` | `flag` | `False` | Skip deep detail page extraction |
| `--no-supabase` | `flag` | `False` | Skip Supabase synchronization |
| `--table` | `str` | `hackathons` | Target Supabase table name |
| `--json-out` | `str` | `hackathons.json` | Destination path for JSON output |
| `--csv-out` | `str` | `hackathons.csv` | Destination path for CSV output |
